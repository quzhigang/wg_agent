🧠 智能体核心 (agents/)

state.py - 状态定义

AgentState TypedDict 定义系统状态

  • 会话信息 (conversation_id, user_id)
  • 意图识别 (intent_category, business_sub_intent)
  • 执行计划 (plan, current_step_index)
  • 工作流上下文 (workflow_context, workflow_status)
  • 页面生成 (generated_page_url, output_type)

planner.py - 规划调度器

最复杂的模块，包含三大提示词模板

  • INTENT_ANALYSIS_PROMPT - 意图识别
  • WORKFLOW_SELECT_PROMPT - 工作流选择
  • PLAN_GENERATION_PROMPT - 计划生成

executor.py - 任务执行器

执行步骤，支持参数变量替换

  • 格式: $$step_1.data[0].stcd$$
  • 递归处理 dict/list 结构

controller.py - 结果合成控制器

独立响应合成，支持并行生成文字和页面

  • 独立对话生成 - LLM 合成简洁文字回复
  • 独立页面生成 - 模板匹配或动态生成 Web 报告
  • 数据注入 - 基于 replacement_config 实现数据动态注入
  • 自动化来源引用 - 为 RAG 结果自动添加参考链接

graph.py - LangGraph状态图

定义节点和路由逻辑
